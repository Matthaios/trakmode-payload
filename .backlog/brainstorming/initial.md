# Trakmode Features

Main purpose of the Trakmode is to help audio creators to create a profile page for their music and connect with their fans. It should be a good replacement for Komi, Linktree, Patreon and other similar platforms.



### Profile page features

Profile page is the main feature of Trakmode. Users should be able to create a profile and have a simple url to it. Ex. trakmode.com/johndoe, trak.link/johndoe, or similar. domain/[username].

- On profile page hero section will be required section and it will have a profile image, cover image, name, tagline and social media links. At some point it will also have follow or bookmark buttons.

- Rest of the page will be customizable and will be able to be edited by the user. It will be a block builder where we will provide different blocks to choose from.

### Blocks

**Youtube video or videos block**: This will be a block that will allow the user to embed a youtube video or videos into their profile page.

**Audio player block**: This will let creator upload their music and have a player for it.

**Embed widgets for other platforms**: This will let creator embed widgets for other platforms like Spotify, Apple Music, SoundCloud, Bandcamp, etc.

**Text block**: This will let creator add a text to their profile page.

**Image block**: This will let creator add an image to their profile page.

**Video block**: This will let creator add a video to their profile page.
