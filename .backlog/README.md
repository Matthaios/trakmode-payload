# Trakmode Backlog

This folder contains all project tasks and features organized as markdown files with structured headers for project tracking.

## Task Status Types

- **🟢 Active**: Currently in progress
- **🟡 Planning**: Being planned or designed
- **🔵 Ready**: Ready to start
- **⏸️ Blocked**: Waiting on dependencies
- **✅ Completed**: Finished and delivered
- **❌ Cancelled**: No longer needed

## Priority Levels

- **🔴 Critical**: Must be completed immediately
- **🟠 High**: Important for current sprint
- **🟡 Medium**: Important but not urgent
- **🟢 Low**: Nice to have

## Task Categories

- **Feature**: New functionality
- **Bug**: Bug fixes
- **Refactor**: Code improvements
- **Infrastructure**: DevOps, deployment, tooling
- **Documentation**: Docs, guides, comments
- **Research**: Investigation, analysis

## File Naming Convention

Tasks are named using the format: `[category]-[short-description]-[date].md`

Examples:
- `feature-user-authentication-2024-01-15.md`
- `bug-payment-webhook-2024-01-16.md`
- `refactor-api-client-2024-01-17.md`

## Task Template

Each task file should include:
- Status and priority in the header
- Clear description and acceptance criteria
- Dependencies and blockers
- Implementation notes
- Testing requirements
- Related files and components
